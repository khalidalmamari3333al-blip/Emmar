# الاختبارات الشاملة (E2E)

تشغّل كود خدمات التطبيق الحقيقي ضد Supabase يعمل محليًا (Postgres + Auth + REST):
البحث، مخطط الأسرّة، التسجيل، طلب الحجز، منع الحجز المزدوج، الخصوصية، والإلغاء.

```bash
bash e2e/start-local.sh   # يحتاج Docker
npm run test:e2e
docker rm -f aq-db aq-auth aq-rest   # للإيقاف
```

- المفاتيح هنا محلية ومولّدة من سر اختبار ثابت، وليست مفاتيح أي مشروع حقيقي.
- مفتاح `service_role` يُستخدم فقط لتجهيز بيانات الاختبار، ولا يدخل التطبيق أبدًا.
